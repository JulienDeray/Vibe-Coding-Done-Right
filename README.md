# Sprint Workshop

## Skills

Custom Claude Code skills are available in the `skills/` directory:

| Skill | Description |
|-------|-------------|
| `/epic` | End-to-end workflow for implementing a feature from a PRD |
| `/pm-spec` | Write detailed PRD specifications from rough backlog ideas |
| `/testing-workflow` | Analyze changes, create tests, and maintain acceptance criteria |
| `/validate` | Run build, lint, and tests to validate code quality |
| `/report-to-pm` | Report implementation completion to PM via Notion |
| `/wrap-up` | Finalize implementation with QA, docs, commit, and reporting |

## Slides

The presentation is built with [Slidev](https://sli.dev/).

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for static deployment
npm run build

# Export to PDF
npm run export
```
